# Source evidence

MODEL_CARD.md is a verbatim public HF model-card snapshot at revision
855cb7601710064aeb7452b6b7e45e60a40be76b. model-config.json is its unmodified model
configuration. They document publisher measurements; raw benchmark JSON,
per-token logits and original native benchmark/vision logs were not available to this recipe. Native MiniCPM source is now merged in the public ExLlamaV3 fork.

../model.lock.json contains per-file size and checksum metadata from the Hub
model API for the same revision. ../bench/published-results.json is a structured
transcription, including measurement scopes. No personal or private SAGE artifacts
are included. Source model/card attribution remains OpenBMB and Victor Cruz.
